# Work Log — 2026-08-06

## Summary
- Implemented content-addressable publish versioning with blob-backed storage and rollback support.

## Tasks
- Added `SitePublishVersion` tracking for publish history and `Site.current_published_version` linking.
- Added `BlobStore` for deduplicated blob storage under `assets/blobs/`.
- Updated `PublishService` to store content hashes, materialize published assets from blobs, and support rollback.
- Added publish-version listing and single version detail endpoints for sites.
- Added rollback endpoint for site publish versions.
- Changed `PublishService.rollback()` behavior: restore editable HTML/CSS/JS source from blobs and then regenerate published JSON assets so the editor remains the single source of truth.
- Fixed rollback restore so pages not present in the target version are disabled before republishing, preventing newer pages from reappearing.
- Updated `SiteRollbackAPIView` to require confirmation (`?confirm=true`) before discarding unpublished edits and to restore source then republish.
