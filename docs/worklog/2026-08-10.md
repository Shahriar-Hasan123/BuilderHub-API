# Work Log — 2026-08-10

## Summary
- Hardened upload-time image optimization and SVG validation, with focused test coverage for the new safety paths.

## Tasks
- Added a "never bigger than original" safety net so compression output falls back to the original file when optimization would increase size.
- Added adaptive compression for JPEG, WEBP, and AVIF using quality steps and bounded resize retries to better satisfy target byte limits.
- Fixed transparent PNG handling so photo-like transparent images are not misclassified through sampled color counts, and quantized transparent PNGs also respect target-size fallback behavior.
- Fixed opaque PNGs (screenshots, diagrams, icons) so they now get the same color-count-based lossless path transparent PNGs already had, instead of being unconditionally converted to lossy JPEG.
- Fixed transparent-PNG size fallback so it now tries lossless WEBP before falling back to lossy WEBP.
- Added a test verifying the `quantize()` "lossless" path is actually pixel-exact for genuinely low-color images.
- Preserved animated image uploads instead of silently collapsing GIF/PNG/WEBP animations to a single frame.
- Added EXIF transpose handling so phone/camera images keep the expected orientation after optimization.
- Added a hard pixel-count guard before raster image loading to reduce decompression-bomb risk.
- Changed raster routing to use Pillow's detected image format instead of trusting the filename extension, and normalized output filenames for mismatched extensions.
- Normalized uncommon image modes before WEBP/AVIF encoding to avoid save-time encoder crashes.
- Replaced weak SVG string checks with safe XML parsing via `defusedxml`.
- Added SVG safety checks for blocked elements, inline event handlers, and unsafe URL values.
- Added SVG dimension validation using `width`/`height` or `viewBox` so SVG uploads follow the same min/max rules as raster images.
- Updated image optimizer and validator tests for format detection, pixel-limit rejection, transparent PNG fallback, SVG dimensions, and unsafe SVG rejection.
