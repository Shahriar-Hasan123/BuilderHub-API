# Work Log — 2026-07-30

## Summary
- Update comprehensive image validation and media fields: `ImageValidator`, `Site.thumbnail`, `Page.hero_image`, and stronger favicon/logo validators.

- Added nested site image CRUD endpoints under `/api/v1/sites/{site_pk}/images/`.

- Added `SiteImageSerializer` and `SiteImageListAPIView` / `SiteImageDetailAPIView`.
